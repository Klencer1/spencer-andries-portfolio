# Spencer Andries Data Science Portfolio

This folder is ready to upload to the root of the GitHub repository:
`Klencer1/spencer-andries-portfolio`

## Publish with GitHub Pages
1. Upload every file and folder in this directory to the repository root.
2. In GitHub, open **Settings > Pages**.
3. Under **Build and deployment**, choose **Deploy from a branch**.
4. Select the **main** branch and **/(root)** folder, then save.
5. The site will be available at `https://klencer1.github.io/spencer-andries-portfolio/`.

## Important
- Keep the folder structure unchanged because the project links use relative paths.
- The website includes PDF versions of reports and slides for browser viewing, original PPTX files where supplied, notebook HTML previews, and original source-code files.
- Large raw datasets are intentionally not included.
